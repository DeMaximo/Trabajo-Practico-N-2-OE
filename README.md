1. Clonar este repositorio localmente o en Google Colab.
2. Descargar el archivo `dataset.csv` e introducirlo en la carpeta `/datos`.
3. Ejecutar el script técnico principal mediante el comando: `python scripts/analisis_datos.py`.
4. Los resultados e indicadores visuales se exportarán automáticamente a la carpeta `/resultados`.
